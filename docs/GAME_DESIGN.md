## 1. 게임 개요

ECHO BREAKER는 20개의 고정 패턴을 제한시간 안에 공략하는 웨이브형 브릭 브레이커다. 플레이어는 패들을 조작하고, 웨이브가 끝날 때마다 스킬을 선택해 공과 패들의 작동 방식을 강화한다. 핵심 재미는 공의 수와 스킬 연쇄가 점차 커지는 시각적 쾌감, 남은 블럭이 코어 피해로 전환되는 시간 압박, 반복 플레이를 데이터로 검증하는 성장 실험에 있다.

### 핵심 설계 목표

1. **즉각적인 쾌감**: 타격, 폭발, 연쇄, 화면 흔들림과 사운드가 피해 규모를 명확하게 전달한다.
2. **직관적인 빌드**: 전사·궁수·법사라는 익숙한 역할로 스킬의 결과를 예측할 수 있어야 한다.
3. **누적되는 임팩트**: 플레이가 길어질수록 공, 연쇄 공격, 광역 효과가 눈에 띄게 커진다.
4. **명확한 위기**: 60초 제한시간과 미파괴 블럭의 CORE 낙하 피해가 지속적인 압박을 만든다.
5. **측정 가능한 밸런스**: 원본 브릭 브레이커부터 요소를 하나씩 추가하며 봇과 지표로 영향력을 비교한다.

## 2. 기본 플레이 루프

1. 런 시작 전에 일반 스킬 후보에서 시작 스킬 2개를 선택한다.
2. 패들로 공을 반사한다.
3. 공이 블럭을 타격하거나 파괴한다.
4. 점수를 즉시 획득하고, 특정 블럭에서는 아이템이 떨어진다.
5. 패턴을 전부 파괴하거나 60초가 지나면 웨이브가 종료된다.
6. 남은 블럭의 CORE 피해와 방어막 차감을 먼저 정산한다.
7. 정산 후 일반 스킬 보상 또는 보스 궁극기 보상을 선택한다.
8. 반사 횟수를 채워 직업 스킬을 발동하고, 공용 스킬은 획득 즉시 상시 적용한다.
9. W10 중간 보스와 W20 최종 보스를 제한시간 안에 격파한다.
10. W20 정산 완료 또는 CORE 파괴까지 진행한다.

## 3. 핵심 게임 규칙

### 패들과 공

- 기본 패들 폭: 128px
- 기본 공 속도: X 240 / Y 320
- 공은 좌우 벽과 천장에 반사된다.
- 맵 바닥은 영구 중립 반사 바닥이다.
- 중립 바닥에 닿은 공은 다시 위로 반사되지만, 패들에서 받은 인챈트·관통·공격력·스킬 충전 상태가 제거되어 기본 공으로 돌아간다.
- 임시 화살은 중립 바닥에 닿거나 제한시간이 끝나면 사라진다.
- 새 웨이브 시작 시 영구 공은 플레이어 패들 위로 재배치되어 다시 발사되고 임시 공은 제거된다.

### CORE와 게임오버

- 기본 CORE 체력: 8
- 웨이브 도중 블럭은 이동하거나 CORE를 공격하지 않는다.
- 60초가 끝나면 남은 모든 블럭이 동시에 CORE로 낙하한다.
- 낙하 피해는 남은 블럭 수·보스 체력·특수 블럭 특성을 위협도로 환산한 뒤 1~6 피해로 압축한다.
- 파괴 불가 블럭은 지형이므로 CORE 피해 정산에서 제외한다.
- 방어막은 계산된 낙하 피해를 충전 수만큼 차감한다.
- CORE 체력이 0이 되면 게임오버다.
- 방어막은 CORE LINE 피해를 1회 막는다.

### 콤보와 점수

- 블럭을 연속으로 파괴하면 콤보와 점수 배율이 증가한다.
- 기본 콤보 유지시간은 1.8초다.
- 공용 스킬과 콤보 아이템으로 유지시간을 늘릴 수 있다.
- 콤보가 높아질수록 브릭 파괴 사운드와 미세한 화면 흔들림이 강해진다.

## 4. 웨이브와 난이도

### 일반 웨이브

- 전체 런은 W1~W20으로 고정된다.
- 각 웨이브는 이름과 형태가 있는 12열 고정 패턴을 사용한다.
- 모든 웨이브의 기본 제한시간은 60초다.
- 제한시간 중 블럭은 내려오지 않으며 추가 일반 라인도 생성되지 않는다.
- 패턴을 모두 파괴하면 남은 시간과 관계없이 즉시 클리어된다.
- 기본 블럭 체력은 5웨이브 구간마다 증가한다.
- 후반 패턴일수록 가드·폭발·회복·반사 블럭과 파괴 불가 지형이 복합 배치된다.

### 보스 웨이브

- 보스는 W10과 W20에 고정 배치된다.
- 보스는 중앙에 고정된 하나의 4×3 CORE FORTRESS로 표현되며 내려오지 않는다.
- 보스도 동일하게 60초 제한시간을 사용한다.
- 보스는 주변에 공격용 블럭을 생성하지만, 생성된 블럭도 웨이브 종료 전까지 내려오지 않는다.
- 보스 기본 체력 계수는 48이며 보스 단계마다 12씩 증가한다.
- 보스 격파 시 일반 레벨업과 분리된 궁극기 보상 화면이 열린다.

## 5. 블럭과 아이템

### 블럭 종류

| 종류 | 규칙 |
|---|---|
| 일반 | 체력을 모두 깎으면 파괴된다. |
| 가드 | 첫 피격을 1회 무효화한다. 분쇄 스킬은 가드를 즉시 제거한다. |
| 폭발 | 파괴될 때 반경 112px 안의 블럭에 1 피해를 주고 충돌한 공을 폭발 바깥으로 강하게 날린다. 연쇄 폭발이 가능하다. |
| 파괴 불가 | 모든 피해와 자동 타겟팅을 무시한다. 패턴의 벽과 통로를 만들며 클리어·CORE 피해 계산에서 제외된다. |
| 회복 | 3초마다 반경 135px 안의 손상된 블럭을 1 회복한다. 각 블럭의 최대 체력을 넘지 않는다. |
| 반사 | 아래에서 위로 진입하는 공을 피해 없이 아래 방향으로 튕겨낸다. 다른 방향에서 맞으면 일반 피해를 받는다. |
| 보스 CORE | 보스의 중앙 고정 본체다. |
| 보스 미니언 | 보스가 생성하는 공격 블럭이며 일반·가드·폭발·회복 속성을 사용할 수 있다. |

### 아이템 종류

| 아이템 | 효과 |
|---|---|
| MULTI BALL | 현재 패들의 효과를 받은 공 1개를 즉시 추가한다. |
| COMBO | 현재 콤보 유지시간을 연장한다. |
| BARRIER | CORE LINE 피해를 1회 막는 방어막을 충전한다. |
| REPAIR | CORE 체력을 1 회복한다. 최대 체력이면 점수로 전환한다. |
| STRIKE | 가장 아래에 있는 위험 블럭을 자동 공격한다. |

- 멀티볼 아이템은 보스 구간마다 고정 예산을 사용해 밸런스 편차를 제한한다.
- 일반 구간의 멀티볼 예정 웨이브는 각 20웨이브 구간 기준 2, 4, 6, 8, 11, 13, 16, 18이다.
- 보스 구간 멀티볼 예산은 2개다.
- 아이템을 가진 블럭은 색과 기호로 구분된다.

## 6. 스킬 시스템

### 공통 규칙

- 스킬 레벨은 LV1~LV3이다.
- 직업 스킬 표의 수치는 **발동에 필요한 해당 패들의 반사 횟수**다. 수치가 낮을수록 자주 발동한다.
- 반사 카운트는 화면 하단에 스킬 아이콘과 `현재/필요` 형식으로 표시한다.
- 임시 화살은 반사 카운트를 올리지 않는다.
- 일반 웨이브 종료 보상에서는 일반 직업 스킬과 공용 패시브만 등장한다.
- 궁극기는 보스 격파 보상으로만 획득한다.
- 스킬 개수 제한은 없고 같은 스킬을 다시 선택하면 레벨이 오른다.
- 각 스킬은 고유 색을 가지며 카드, 패들 아이콘, 충전된 공, 발동과 타격 이펙트에 동일하게 사용한다.

### 전사

전사는 직접 피해, 방어 파괴, 저체력 처형과 CORE 방어에 집중한다.

| 구분 | 스킬 | LV1/LV2/LV3 | 효과 |
|---|---|---:|---|
| 일반 | 강타 | 3/2/1 | 다음 직접 공격에 레벨만큼 추가 피해 |
| 일반 | 충격파 | 6/5/4 | 충전된 공이 블럭을 파괴하면 주변 폭발 |
| 일반 | 처형 | 7/5/3 | 체력 25% 이하 일반 블럭 즉시 파괴 |
| 일반 | 분쇄 | 5/4/3 | 가드 제거 및 파괴 불가를 제외한 특수 블럭 추가 피해 |
| 일반 | 철벽 | 14/11/8 | CORE LINE 방어막 1회 충전 |
| 궁극기 | 대지 분쇄 | 18/14/10 | 모든 일반 블럭에 1 피해 |
| 궁극기 | 광전사 | 15/12/9 | 충전된 공의 공격력과 속도 대폭 증가 |

|---|---|---:|---|
| 일반 | 연사 | 8/6/4 | 임시 화살 1발 생성. 약 4.75/5.5/6.25초 후 소멸 |

### 공용 패시브

공용 스킬은 직업과 무관하게 획득 즉시 상시 적용되며 반사 카운트를 사용하지 않는다.

| 스킬 | LV1/LV2/LV3 | 효과 |
|---|---:|---|
| 아이템 자석 | 70/120/180px | 아이템 흡수 범위 증가 |
| 행운 | 8/14/20% | 아이템이 없는 블럭의 추가 드롭 확률 증가 |
| 패들 확장 | 20/35/50px | 실제 충돌 범위를 포함한 패들 길이 증가 |
| 학습 가속 | 1/2/3 XP | 블럭 파괴 시 기본 경험치 추가 획득 |
| 콤보 안정화 | 0.6/1.2/2초 | 콤보 유지시간 증가 |

## 7. 시각·사운드 피드백

- 일반 피격, 블럭 파괴, 스킬 타격, 폭발, 치명타, 궁극기와 CORE 피해는 서로 다른 강도의 화면 흔들림을 사용한다.
- 강한 스킬은 고유 색상의 전체 화면 플래시를 발생시킨다.
- 충전된 공은 스킬 색상의 궤도를 표시한다.
- 임시 화살은 공 외곽의 수명 게이지로 남은 시간을 표시한다.
- 폭발은 방사형 광원, 이중 링, 파티클 궤적을 사용한다.
- 사운드는 피격음, 파괴음, 폭발음, 치명타음, 스킬음, 궁극기음, 보스음과 CORE 피해음으로 구분한다.
- 여러 효과가 겹칠 때의 클리핑을 줄이기 위해 다이내믹 컴프레서를 사용한다.

## 8. 밸런스 검증 구조

### 누적 벤치마크 단계

| 단계 | 활성 요소 |
|---:|---|
| 0 | ORIGINAL: 순수 브릭 브레이커 |
| 1 | + PRESSURE: 하강 웨이브와 CORE LINE |
| 2 | + ITEMS |

### 스킬 벤치 환경

- **Original**: 스킬이 없는 기준군
- **Isolated**: 선택한 스킬만 적용해 LV0/LV1/LV2/LV3 비교
- **Ecosystem**: 실제 아이템·블럭·보스 환경에서 스킬 영향 측정
- 단일 스킬 또는 카테고리·전체 스킬 배치를 지원한다.
- 봇은 1×/2×/4×/8× 배속으로 실행할 수 있다.
- 기본 반복 수는 변형당 5회이며 3회 또는 10회로 조절할 수 있다.
- 목표 웨이브는 20/40/60/100 중 선택한다.

### 주요 평가 지표

- 도달 웨이브와 생존시간
- 점수와 최대 콤보
- 최대 공 개수와 공 손실 횟수
- CORE 잔여 체력
- 생존 보조 효과 발동 횟수
- 웨이브별 필드 생존 블럭 수와 총 체력
- 스킬 LV0 대비 LV1/LV2/LV3 변화량

### 우선 검토 항목

1. 각 직업의 일반 스킬 5개가 실제로 서로 다른 플레이 감각을 만드는가?
2. 반사 횟수만 낮아지는 레벨업이 충분히 매력적인가, 효과 수치도 함께 성장해야 하는가?
3. 단일 타격, 공 생성, 광역 제거, 생존 보조의 기대 가치가 같은 선택 화면에서 비교 가능한가?
4. 궁극기가 보스 보상에 걸맞은 화면 변화와 빌드 전환을 만드는가?
5. 공용 패시브가 직업 스킬보다 항상 안전한 선택이 되지 않는가?
6. 공이 많아질수록 반사 기반 스킬의 발동 빈도가 과도하게 증가하지 않는가?

### 권장 작업 순서

1. 스킬별 의도와 대표 장면을 한 문장으로 정의한다.
2. Original 기준군과 직업별 단일 스킬 LV1을 비교한다.
3. 발동 횟수, 파괴 속도, 생존시간과 공 개수 변화량을 확인한다.
4. 지나치게 강한 스킬은 효과를 약화하기 전에 발동 조건과 대상 제한을 먼저 조정한다.
5. 직업별 2~3개 스킬 조합을 실험해 시너지가 의도대로 발생하는지 확인한다.
6. 마지막으로 궁극기를 추가해 보스 이후 파워 스파이크를 측정한다.

### 미결정 사항

- 레벨업 선택지의 직업별 등장 가중치
- 한 런에서 특정 직업을 고정하거나 자유 혼합할지 여부
- 공용 스킬의 최대 등장 비율
- 궁극기 선택지를 매번 6개 모두 보여줄지 3개만 추첨할지 여부
- 스킬별 최대 레벨 이후 중복 선택 처리
- W20 완주율과 W10·W20 보스별 목표 통과율

## 11. 변경 관리 원칙

- 기능 변경은 구현, 빌드, 회귀 테스트, 기획 문서 갱신, 기능 단위 커밋 순서로 마무리한다.
- 스킬 수치 변경은 Skill LAB에서 먼저 실험하고 확정된 값만 기본 설정에 반영한다.
- 구현과 문서가 다르면 구현을 임시 기준으로 삼되 같은 작업에서 문서를 맞춘다.
- 밸런스 변경 커밋에는 변경 이유와 비교 지표를 함께 남긴다.
