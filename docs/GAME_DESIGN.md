# CORE BREAKER 게임 기획서

> 문서 버전: 0.9
>
> 기준 빌드: 2026-07-18 `main`
>
> 상태: 플레이 가능한 프로토타입 / 스킬 디자인 및 밸런스 검증 단계

## 1. 게임 개요

CORE BREAKER는 기본 공 1개로 20개의 고정 패턴을 차례로 돌파하는 웨이브형 브릭 브레이커다. 플레이어는 포인터나 터치로 패들을 조작하고, 웨이브가 끝날 때마다 스킬을 선택해 공과 패들의 작동 방식을 강화한다. 패들의 이동 방향은 공의 반사 방향에 추가로 영향을 준다. 핵심 재미는 한 개의 공과 블럭 기능을 정확히 읽는 플레이, 충전된 스킬이 만드는 명확한 파괴 효과, 공 손실로 CORE가 줄어드는 지속적인 위기에 있다.

### 핵심 설계 목표

1. **즉각적인 쾌감**: 타격, 폭발, 연쇄, 화면 흔들림과 사운드가 피해 규모를 명확하게 전달한다.
2. **직관적인 빌드**: 전사·궁수·법사라는 익숙한 역할로 스킬의 결과를 예측할 수 있어야 한다.
3. **집중되는 임팩트**: 기본 공 1개를 유지해 플레이어의 시선을 블럭 기능과 스킬 발동 결과에 집중시킨다.
4. **명확한 위기**: 공을 놓칠 때마다 CORE 1이 감소하고 즉시 새 공으로 이어지는 구조가 지속적인 압박을 만든다.
5. **측정 가능한 밸런스**: 원본 브릭 브레이커부터 요소를 하나씩 추가하며 봇과 지표로 영향력을 비교한다.

## 2. 기본 플레이 루프

1. 런 시작 전에 일반 스킬 후보에서 시작 스킬 2개를 선택한다.
2. 패들로 공을 반사한다.
3. 공이 블럭을 타격하거나 파괴한다.
4. 점수를 즉시 획득하고, 특정 블럭에서는 아이템이 떨어진다.
5. 파괴 가능한 블럭을 전부 제거하면 웨이브가 종료된다.
6. 클리어 정산에서 소요시간과 현재 CORE를 확인한다.
7. 정산 후 일반 스킬 보상 또는 보스 궁극기 보상을 선택한다.
8. 반사 횟수를 채워 직업 스킬을 발동하고, 공용 스킬은 획득 즉시 상시 적용한다.
9. W10 중간 보스와 W20 최종 보스를 격파한다.
10. W20 클리어 또는 CORE 파괴까지 진행한다.

## 3. 핵심 게임 규칙

### 패들과 공

- 기본 패들 폭: 128px
- 기본 공 속도: X 240 / Y 320
- 공은 좌우 벽과 천장에 반사된다.
- 웨이브 경과 30/50/70/90초에 OVERDRIVE가 발동해 현재 공 속도가 5%씩 증가하며 최대 120%로 제한된다. 다음 웨이브에서는 100%로 초기화한다.
- 패들 반사는 공과 이동 중인 패들의 연속 교차 지점을 계산한다. 이미 표면에 얕게 겹친 공도 허용 오차 안에서 구조하고, 충돌 직전의 전체 속력을 보존하면서 타격 위치와 패들 이동 방향으로 각도만 조절한다.
- 블럭 충돌은 원–사각형 접촉점과 법선을 사용하고 반사 직후 공을 충돌면 밖으로 분리해 모서리 오판정과 중복 타격을 방지한다.
- 맵 바닥에는 영구 반사 구역이 없으며, 패들 아래로 빠진 기본 공은 손실 처리된다.
- 기본 공을 놓치면 CORE 1을 차감하고 플레이어 패들 위에 새 기본 공 1개를 즉시 소환한다.
- 임시 화살은 정해진 수명이 끝나면 사라지며 CORE 피해를 발생시키지 않는다.
- 모든 웨이브는 기본 공 1개로 시작한다.
- 새 웨이브 시작 시 기본 공은 플레이어 패들 위로 재배치되어 다시 발사된다.
- 일반 공 본체는 공격력과 충전 스킬에 관계없이 노란색으로 통일한다.
- 멀티볼 아이템으로 생성된 웨이브 보너스 공은 회색으로 표시되며 현재 웨이브 종료 후 제거된다.
- 임시 화살도 새 웨이브 시작 시 제거된다.

### CORE와 게임오버

- 기본 CORE 체력: 8
- 웨이브 도중 블럭은 이동하거나 CORE를 직접 공격하지 않는다.
- 웨이브 제한시간과 잔여 블럭 낙하 정산은 사용하지 않는다.
- 기본 공 손실 1회당 CORE 1 피해를 즉시 적용한다.
- 보너스 멀티볼과 임시 화살의 손실은 CORE 피해를 발생시키지 않는다.
- 방어막은 별도 CORE 방어 스킬 규칙에 따라 작동하며 공 손실 비용을 대신하지 않는다.
- CORE 체력이 0이 되면 게임오버다.
- 방어막은 CORE LINE 피해를 1회 막는다.

### 콤보와 점수

- 블럭을 연속으로 파괴하면 콤보와 점수 배율이 증가한다.
- 기본 콤보 유지시간은 1.8초다.
- 공용 스킬과 콤보 아이템으로 유지시간을 늘릴 수 있다.
- 콤보가 높아질수록 브릭 파괴 사운드와 미세한 화면 흔들림이 강해진다.

## 4. 웨이브와 난이도

### 일반 웨이브

- 전체 런은 W1~W20으로 고정된다.
- 각 웨이브는 이름과 형태가 있는 12열 고정 패턴을 사용한다.
- 웨이브 제한시간은 없으며 플레이 시간은 경과시간으로만 기록한다.
- 경과시간이 길어질수록 OVERDRIVE 단계가 올라가 공격 주기와 공 손실 위험이 동시에 증가한다.
- 블럭은 내려오지 않으며 추가 일반 라인도 생성되지 않는다.
- 파괴 가능한 블럭을 모두 제거하면 즉시 클리어된다. 파괴 불가 블럭은 클리어 판정에서 제외한다.
- 기본 블럭 체력은 2웨이브 구간마다 증가하며, 강화 블럭은 3웨이브마다 추가 체력을 얻는다.
- W6~W9는 5줄, W11~W15는 6줄, W16~W19는 7줄 패턴을 기본으로 사용한다.
- 후반 패턴은 빈칸을 줄이고 가드·폭발·회복·반사 블럭과 파괴 불가 지형을 촘촘하게 복합 배치한다.
- 폭발 블럭은 웨이브당 하나의 행에만 분산 배치하고 같은 행에서도 사이에 최소 두 칸을 둔다. 폭발 연쇄는 국소 보상으로 남기되 한 번에 전체 행이 제거되지 않게 한다.

### 보스 웨이브

- 보스는 W10과 W20에 고정 배치된다.
- 보스는 중앙에 고정된 하나의 4×3 CORE FORTRESS로 표현되며 내려오지 않는다.
- 보스도 제한시간 없이 본체와 방어 블럭을 모두 제거할 때까지 진행한다.
- 보스는 주변에 공격용 블럭을 생성하지만, 생성된 블럭도 웨이브 종료 전까지 내려오지 않는다.
- 보스 기본 체력 계수는 280이며 보스 단계마다 160씩 증가한다. W10 보스는 440 HP, W20 보스는 600 HP다.
- 보스 증원 주기는 기본 3.8초이며 후반 보스일수록 더 짧아진다.
- 보스 격파 시 일반 레벨업과 분리된 궁극기 보상 화면이 열린다.

## 6. 스킬 시스템

### 공통 규칙

- 스킬 레벨은 LV1~LV3이다.
- 직업 스킬 표의 수치는 **발동에 필요한 해당 패들의 반사 횟수**다. 수치가 낮을수록 자주 발동한다.
- 반사 카운트는 화면 하단에 스킬 아이콘과 `현재/필요` 형식으로 표시한다.
- 임시 화살은 반사 카운트를 올리지 않는다.
- 일반 웨이브 종료 보상에서는 일반 직업 스킬과 공용 패시브만 등장한다.
- 궁극기는 보스 격파 보상으로만 획득한다.
- 스킬 개수 제한은 없고 같은 스킬을 다시 선택하면 레벨이 오른다.
- 각 스킬은 고유 색을 가지며 카드, 패들 아이콘, 충전된 공, 발동과 타격 이펙트에 동일하게 사용한다.
- 반사 횟수 카운터는 화면 하단에 48×24px 단위로 표시하고 스킬이 많아지면 최대 10개씩 줄바꿈한다.
- 충전율 75%부터 패들 테두리와 글로우가 해당 스킬 색으로 변하며, 충전 완료 순간에는 1.2초 동안 강한 펄스가 표시된다.

스킬은 두 축으로 분류한다. **직업 카테고리**는 빌드의 정체성(전사·궁수·법사·공용)을, **작동 카테고리**는 플레이 중 기대할 결과를 나타낸다.

| 작동 카테고리 | 의미 |
|---|---|
| 타격 | 한 대상에 즉시 큰 피해 또는 처형 |
| 연쇄 | 최초 충돌에서 주변 대상으로 피해 확산 |
| 제어 | 특수 블럭 기능, 회복, 공의 궤적을 통제 |
| 소환 | 일정 시간 존재하는 추가 투사체 생성 |
| 방어 | CORE 피해를 막거나 생존 수단 제공 |
| 지속 | 획득 즉시 계속 적용되는 공용 패시브 |
| 궁극 | 보스 보상으로만 얻는 대규모 효과 |

Skill LAB과 스킬 선택 카드는 두 카테고리를 함께 표시하며, Skill LAB에서는 두 축을 각각 필터링할 수 있다.

### 공용 패시브

공용 스킬은 직업과 무관하게 획득 즉시 상시 적용되며 반사 카운트를 사용하지 않는다.

| 스킬 | LV1/LV2/LV3 | 효과 |
|---|---:|---|
| 아이템 자석 | 70/120/180px | 아이템 흡수 범위 증가 |
| 행운 | 8/14/20% | 아이템이 없는 블럭의 추가 드롭 확률 증가 |
| 패들 확장 | 20/35/50px | 실제 충돌 범위를 포함한 패들 길이 증가 |
| 코어 강화 | 1/2/3 HP | CORE 최대 체력과 현재 체력 증가 |
| 콤보 안정화 | 0.6/1.2/2초 | 콤보 유지시간 증가 |

## 7. 시각·사운드 피드백

- 일반 피격, 블럭 파괴, 스킬 타격, 폭발, 치명타, 궁극기와 CORE 피해는 서로 다른 강도의 화면 흔들림을 사용한다.
- 강한 스킬은 고유 색상의 전체 화면 플래시를 발생시킨다.
- 공격력은 공 크기, 외곽 링 개수와 잔상 길이로 표시하며 본체 색을 변경하지 않는다.
- 충전된 공은 전사의 충격 링, 궁수의 화살 잔상, 마법사의 회전 파티클로 직업을 구분한다. 스킬 고유 색은 이펙트에만 사용한다.
- 폭발 블록과 폭발형 스킬은 CC0 링 폭발 스프라이트를 재생하며, 에셋 로딩 실패 시 기존 절차형 폭발로 안전하게 대체한다.
- 일반 블록 피격은 9프레임 CC0 스파크를 재생하고, 가드 피격은 더 크고 짧은 별도 변형으로 구분한다.
- 전사의 강타·처형·분쇄는 주황색 방사형 번개를, 궁수 약점 치명타는 금색 방사형 번개를 재생한다.
- 전사 스킬은 강타의 교차 궤적, 충격파의 삼중 파동, 처형의 수직 칼날, 분쇄의 사각 파편, 철벽의 육각 방패, 대지 분쇄의 지면 균열, 광전사의 회전 화염으로 서로 구분한다.
- 궁수 스킬은 연사의 평행 화살, 관통의 긴 창끝, 도탄의 지그재그 궤적, 집중의 수축 조준경, 약점의 회전 십자 표적, 화살비의 수직 낙하, 무한 관통의 ∞ 궤적으로 서로 구분한다.
- 법사 스킬은 화염구의 회전 불꽃, 번개의 분기 전류, 빙결의 결정 성장, 블랙홀의 나선 흡입, 마력 봉인의 자색 잠금선, 원소 폭풍의 삼색 고리, 운석의 수직 낙하로 서로 구분한다.
- 법사 화염구가 충전된 공은 이동 방향을 따르는 6프레임 화염구를, 연쇄 번개 공은 6프레임 마력 스파크를 표시한다.
- 임시 화살은 공 외곽의 수명 게이지로 남은 시간을 표시한다.
- 폭발은 방사형 광원, 이중 링, 파티클 궤적을 사용한다.
- 사운드는 피격음, 파괴음, 폭발음, 치명타음, 스킬음, 궁극기음, 보스음과 CORE 피해음으로 구분한다.
- 여러 효과가 겹칠 때의 클리핑을 줄이기 위해 다이내믹 컴프레서를 사용한다.

## 8. 밸런스 검증 구조

### 공간 분리

- `/`: 실제 게임플레이 공간
- `/benchmark`: 실제 게임과 동일한 W1–W20 스테이지를 반복 실행하는 단일 봇 벤치마크 공간
  - `HEADLESS`는 최대 8개 Worker로 3~1,000회를 병렬 실행해 통계 데이터를 만든다.
  - `WATCH RUN`은 실제 캔버스 물리와 이펙트를 사용하며 1×/2×/4×/8× 배속으로 한 회차를 관찰한다.
  - WATCH RUN 결과는 관찰용으로 분리해 HEADLESS 집계 데이터에 섞지 않는다.
  - 실행 결과는 W20 완료율, 평균 도달 웨이브, 점수·파괴·콤보·코어 KPI로 요약한다.
  - 웨이브별 도달률과 평균 코어 체력은 그래프로, 각 실행은 회차별 데이터 표로 표시한다.
- `/skill-lab`: 스킬 데이터 편집, 빌드 구성과 개별 스킬 실험 공간

### 누적 벤치마크 단계

| 단계 | 활성 요소 |
|---:|---|
| 0 | ORIGINAL: 순수 브릭 브레이커 |
| 1 | + PRESSURE: 하강 웨이브와 CORE LINE |
| 2 | + ITEMS |
| 3 | + BRICK TYPES |
| 4 | + SKILLS |
| 5 | + BOSSES |

### 스킬 벤치 환경

- **Original**: 스킬이 없는 기준군
- **Isolated**: 선택한 스킬만 적용해 LV0/LV1/LV2/LV3 비교
- **Ecosystem**: 실제 아이템·블럭·보스 환경에서 스킬 영향 측정
- 단일 스킬 또는 카테고리·전체 스킬 배치를 지원한다.
- 봇은 1×/2×/4×/8× 배속으로 실행할 수 있다.
- 기본 반복 수는 변형당 5회이며 3회 또는 10회로 조절할 수 있다.
- 목표 웨이브는 20/40/60/100 중 선택한다.

### 주요 평가 지표

- 도달 웨이브와 웨이브별 클리어 소요시간
- 점수와 최대 콤보
- 최대 공 개수와 공 손실 횟수
- CORE 잔여 체력
- 생존 보조 효과 발동 횟수
- 웨이브별 클리어 소요시간과 공 손실 위험
- 스킬 LV0 대비 LV1/LV2/LV3 변화량

## 9. 오늘의 스킬 디자인 과제

### 우선 검토 항목

1. 각 직업의 일반 스킬 5개가 실제로 서로 다른 플레이 감각을 만드는가?
2. 반사 횟수만 낮아지는 레벨업이 충분히 매력적인가, 효과 수치도 함께 성장해야 하는가?
3. 단일 타격, 공 생성, 광역 제거, 생존 보조의 기대 가치가 같은 선택 화면에서 비교 가능한가?
4. 궁극기가 보스 보상에 걸맞은 화면 변화와 빌드 전환을 만드는가?
5. 공용 패시브가 직업 스킬보다 항상 안전한 선택이 되지 않는가?
6. 멀티볼을 획득한 웨이브에서 반사 기반 스킬의 발동 빈도가 과도하게 증가하지 않는가?

### 권장 작업 순서

1. 스킬별 의도와 대표 장면을 한 문장으로 정의한다.
2. Original 기준군과 직업별 단일 스킬 LV1을 비교한다.
3. 발동 횟수, 파괴 속도, 생존시간과 공 개수 변화량을 확인한다.
4. 지나치게 강한 스킬은 효과를 약화하기 전에 발동 조건과 대상 제한을 먼저 조정한다.
5. 직업별 2~3개 스킬 조합을 실험해 시너지가 의도대로 발생하는지 확인한다.
6. 마지막으로 궁극기를 추가해 보스 이후 파워 스파이크를 측정한다.

### 미결정 사항

- 레벨업 선택지의 직업별 등장 가중치
- 한 런에서 특정 직업을 고정하거나 자유 혼합할지 여부
- 공용 스킬의 최대 등장 비율
- 궁극기 선택지를 매번 6개 모두 보여줄지 3개만 추첨할지 여부
- 스킬별 최대 레벨 이후 중복 선택 처리
- W20 완주율과 W10·W20 보스별 목표 통과율
