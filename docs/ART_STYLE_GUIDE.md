# CORE BREAKER 아트 스타일 가이드

이 문서는 CORE BREAKER의 배경, 블록, 보스, 이펙트, UI 리소스가 하나의 게임처럼 보이도록 유지하기 위한 기준 문서다.

새로운 아트 리소스를 제작하거나 외부 이미지를 적용할 때 반드시 이 문서의 규격과 체크리스트를 먼저 확인한다.

## 1. 프로젝트 기준

| 항목 | 기준 |
| --- | --- |
| 게임 캔버스 | 900×600 logical canvas |
| 배경 제작 기준 | 450×300 저해상도 픽셀 아트 후 2배 nearest 확대 |
| 블록 기준 크기 | 98×28 px |
| 보스 배치 | 4열×3행 |
| 보스 외곽 장갑 | 일반 블록 크기 8개 |
| 보스 코어 | 하나의 2×2 블록 영역 |
| 이펙트 시트 | 기본 4×2, 8프레임 |
| 픽셀 확대 | nearest-neighbor, smoothing 없음 |
| 폰트 | Neo둥근모 |

## 2. 핵심 스타일

### 시점

- 모든 게임 요소는 정면을 바라보는 2D 픽셀 아트로 제작한다.
- 등각 투영, 사선 원근, 입체 큐브, 3D 렌더링 표현은 사용하지 않는다.
- 블록은 평평한 가로형 석재 패널로 표현한다.
- 보스 코어도 일반 보스 블록과 같은 정면 시점을 유지한다.

### 픽셀 밀도

- 기존 게임 블록과 같은 픽셀 밀도를 사용한다.
- 선명한 픽셀 클러스터를 유지하고 과도한 안티앨리어싱을 피한다.
- 가장자리에는 어두운 픽셀 외곽선을 사용한다.
- 이미지마다 임의로 해상도나 픽셀 크기를 바꾸지 않는다.

### 외곽선

- 기본 외곽선: 어두운 차콜 또는 청회색.
- 강조 외곽선: 리소스의 대표 색상보다 밝은 1~3px 픽셀 라인.
- UI 프레임의 외곽선은 게임 블록보다 조금 더 정돈되고 두껍게 표현한다.
- 부드러운 벡터 라인이나 사진풍 테두리는 금지한다.

## 3. 배경 컨셉

### 확정된 세계관

CORE BREAKER의 게임 배경은 고대 성벽 위의 마법 경기장이다.

- 플레이어는 오래된 성채 외곽의 석조 발코니에 위치한다.
- 중앙 전장 뒤에는 코어 마법으로 움직이는 고대 성채가 보인다.
- 좌우에는 동일한 석조 기둥과 깃발이 배치된다.
- 하단에는 어두운 발코니 바닥과 낮은 난간을 둔다.
- 원경은 산맥, 안개, 성채 실루엣으로 구성한다.
- 중앙 상단은 블록과 보스가 읽히도록 단순한 하늘 영역을 유지한다.

### 배경 표현 방식

배경은 입체적인 다크 판타지 일러스트가 아니라 저해상도 2D 픽셀 도트 그래픽으로 제작한다.

- 기준 제작 해상도는 450×300이다.
- 게임 캔버스에서는 900×600으로 2배 nearest 확대한다.
- 모든 오브젝트는 정면 2D 시점과 픽셀 실루엣을 사용한다.
- 사실적인 원근, 3D 모델링, 부드러운 페인팅, 사진풍 안개는 사용하지 않는다.
- 구름·안개·산맥은 큰 픽셀 덩어리와 제한된 색상 단계로 표현한다.
- 건물은 세부 묘사보다 계단식 윤곽과 창문 불빛의 패턴으로 표현한다.
- 배경의 광원은 부드러운 블룸이 아니라 계단식 픽셀 발광으로 처리한다.
- 배경은 게임 블록과 공보다 대비가 낮아야 한다.

### 배경 명암 기준

- 배경당 주요 색상은 12~20색으로 제한한다.
- 명암 단계는 최대 5단계로 제한한다.
- 게임 요소가 위치하는 중앙 전장에는 낮은 대비의 단순한 영역을 확보한다.
- 공과 패들이 위치하는 하단은 가장 어둡게 처리한다.
- 성채와 산맥은 전경보다 1~2단계 어둡게 처리한다.
- 코어·룬·스킬 이펙트가 배경에 묻히지 않도록 배경 광원은 절제한다.

### 웨이브별 배경 변형

기둥, 발코니, 게임 영역의 위치와 비율은 모든 웨이브에서 유지한다. 웨이브가 바뀔 때는 팔레트, 하늘, 원경 실루엣, 파티클만 변경한다.

| 웨이브 | 배경 컨셉 | 대표 팔레트 |
| --- | --- | --- |
| 1~5 | 달빛이 비추는 푸른 성채 | 네이비·청색·은색 |
| 6~10 | 저주받은 늪과 폐허 | 청록·짙은 녹색 |
| 11~15 | 화산과 불타는 요새 | 적색·주황·암갈색 |
| 16~20 | 공허 위의 부유 성채 | 보라·자색·짙은 남색 |

### 배경 안전 영역

```text
[좌측 고정 기둥] [단순한 하늘과 원경 성채] [우측 고정 기둥]
                  [게임 블록 영역]
                  [공 이동 영역]
                  [어두운 발코니 바닥]
```

- 중앙 상단은 복잡한 건축물이나 밝은 달을 겹치지 않는다.
- 좌우 UI 여백에는 강한 파티클과 밝은 광원을 배치하지 않는다.
- 중앙 게임 영역의 배경은 블록 외곽선이 읽힐 만큼 어둡고 단순해야 한다.
- 배경 애니메이션은 미세한 안개, 파티클, 깜빡이는 창문, 느린 광원 변화만 허용한다.

## 4. 조명과 재질

### 공통 광원

- 주 광원은 위쪽과 중앙에서 들어온다.
- 밝은 면은 위쪽, 어두운 면은 아래쪽에 둔다.
- 금속 장식에는 짧은 하이라이트 픽셀을 사용한다.
- 발광 요소는 내부 발광을 우선하고 외부 글로우는 제한적으로 사용한다.

### 재질

| 재질 | 표현 방식 |
| --- | --- |
| 석재 | 청회색, 균열, 거친 픽셀 질감 |
| 금속 | 저채도 금색 또는 은색, 짧은 하이라이트 |
| 룬 | 명확한 기하학 문양, 내부 발광 |
| 마법 코어 | 밝은 중심점, 단계적인 색상 그라데이션 |
| 파티클 | 작은 픽셀 클러스터, 방향성 있는 분산 |

과도한 사실적 반사, 유리 질감, 사진풍 그림자는 사용하지 않는다.

## 5. 공통 색상 팔레트

모든 리소스는 아래 팔레트를 기반으로 한다. 새 색상을 추가할 때는 기존 색상과 역할이 겹치지 않는지 확인한다.

| 역할 | 색상 방향 | 사용처 |
| --- | --- | --- |
| 배경 네이비 | `#071326` ~ `#15284a` | 게임 배경, 패널 내부 |
| 석재 차콜 | `#303746` ~ `#596274` | 블록, 프레임 |
| 어두운 외곽선 | `#0a101c` ~ `#171d2a` | 모든 외곽선 |
| 금색 장식 | `#8c6428` ~ `#f0bd55` | UI 장식, 보스 장갑 |
| 은색 장식 | `#aab4c5` ~ `#f1f5ff` | 프레임, 보조 금속 |
| 코어 청색 | `#238de0` ~ `#b8f3ff` | 코어, 초기 룬 |
| 마법 보라 | `#7738c8` ~ `#e0a8ff` | 중후반 룬, 보호막 |
| 위험 주황 | `#c94726` ~ `#ffd166` | 폭발, 경고 |
| 회복 녹색 | `#4f9e25` ~ `#caff70` | 힐러, 회복 |
| 쿨타임 딤 | `rgba(5, 7, 14, .68)` | 스킬 아이콘 쿨타임 |

색상은 쨍한 네온 단색보다 어두운 기반색과 밝은 중심색의 2~4단계 조합을 사용한다.

## 6. 게임 요소별 기준

### 일반 블록

- 98×28 비율을 유지한다.
- 좌우 끝 장식은 9-slice 사용 시 모서리 캡으로 분리한다.
- 중앙 장식은 반복되거나 늘어나지 않도록 별도 레이어로 처리한다.
- 블록 종류별 대표색은 분명히 구분하되 공통 석재 구조는 유지한다.

### 보스

- 기본 구조는 다음과 같다.

```text
[장갑] [코어] [코어] [장갑]
[장갑] [코어] [코어] [장갑]
[장갑] [장갑] [장갑] [장갑]
```

- 외곽 장갑은 일반 블록과 같은 크기와 정면 시점을 사용한다.
- 코어는 4개의 서로 다른 블록을 조합하지 않고, 하나의 2×2 코어 블록 이미지로 제작한다.
- 코어의 중심 광원과 룬 문양은 장갑보다 명확해야 한다.
- Wave 5/10/15/20은 색상과 장식만 변경하고 기본 실루엣은 유지한다.
- 보호 룬, 돌출 예고, 중력 룬은 블록 본체가 아니라 별도 2D 이펙트로 제작한다.

### 공과 패들

- 플레이어 공은 흰색 기반의 밝은 구체로 배경과 명확하게 분리한다.
- 추가 공은 플레이어 공과 다른 색상으로 구분한다.
- 공 주변에는 과도한 외곽 사각형이나 불투명 배경이 없어야 한다.
- 패들은 블록과 같은 금속·석재 재질 언어를 공유한다.

### 스킬 이펙트

- 이펙트는 2D 정면 픽셀 아트로 제작한다.
- 스프라이트 시트는 기본 4×2, 총 8프레임으로 만든다.
- 프레임 구조는 `예고 → 발동 → 유지 → 소멸` 순서를 따른다.
- 궤적형 이펙트와 블록 중심형 이펙트의 기준점을 분리한다.
- 이펙트마다 실제 표시 크기는 다르게 설정하되 픽셀 밀도는 동일하게 유지한다.
- 투명 배경을 사용하며, 검정 또는 초록색 배경이 최종 리소스에 남아서는 안 된다.
- 플레이어 스킬과 보스 스킬은 같은 픽셀 밀도와 광원 규칙을 사용한다.

## 7. UI 기준

- 타이틀 화면, 인게임 패널, 스킬 선택 창은 같은 UI 컴포넌트 체계를 공유한다.
- 패널은 9-slice를 사용하며, 모서리와 변의 장식이 늘어나지 않도록 구성한다.
- 모서리 장식은 고정하고, 변과 중앙은 반복 또는 평탄한 영역으로 만든다.
- 버튼·패널·프레임의 금속색과 외곽선 두께를 통일한다.
- 모든 화면에서 좌우 정보 패널의 폭과 내부 여백을 유지한다.
- 아이콘은 동일한 캔버스 크기, 외곽선 두께, 내부 여백을 사용한다.
- 텍스트는 Neo둥근모를 사용한다.
- 강조 텍스트는 색상보다 크기와 외곽선 대비로 우선 구분한다.

## 8. 애니메이션 기준

- 배경은 미세한 안개, 파티클, 빛의 맥동만 사용한다.
- UI는 짧은 슬라이드와 페이드 중심으로 연출한다.
- 룬 링은 슬롯 위치를 유지하면서 천천히 회전한다.
- 코어는 약한 맥동과 중심 발광을 사용한다.
- 이펙트의 외부 글로우가 배경을 덮어 게임 요소의 실루엣을 잃게 만들지 않는다.

## 9. 리소스 제작 규칙

새 리소스는 다음 순서로 제작한다.

1. 기존 기준 리소스 확인
2. 스타일 가이드의 시점·색상·픽셀 밀도 적용
3. 투명 배경 또는 정확한 크로마키 배경으로 생성
4. 실제 프레임 또는 블록 크기로 정규화
5. 알파 채널과 가장자리 색 번짐 검수
6. 게임 화면에 적용
7. 기존 리소스와 함께 표시하여 통일감 검수

이미지 생성 프롬프트에는 항상 다음 제약을 포함한다.

```text
front-facing 2D pixel art, same pixel density as the existing CORE BREAKER blocks,
dark fantasy stone and metal, restrained gold trim, crisp pixel clusters,
no 3D rendering, no perspective, no isometric view, no text, no UI,
transparent-safe background, no cast shadow, no realistic materials
```

- [ ] 배경 또는 크로마키 색이 남아 있지 않은가?
