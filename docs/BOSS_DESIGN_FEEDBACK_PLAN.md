# 보스 디자인 피드백 계획

## 목적

보스 본체, 공격 패턴, 증원 블록, 시각 전조와 보스 보상 UI를 단계적으로 점검하고 확정한다.

## 현재 보스 구조

- 보스 웨이브: W5 초기 보스, W10 중간 보스, W15 후반 보스, W20 최종 보스
- 보스 본체: 4열 × 3행 형태
- 코어: 상단 중앙의 2×2 단일 히트박스, HP 하나를 공유
- 장갑: 코어 바깥쪽 8개 블록
- 보스 클리어 조건: 코어 HP가 0 이하
- 공격 패턴으로 생성된 증원은 클리어 조건에 포함하지 않음

## 보스 전용 패턴

- 보스 단계별 활성 패턴 목록은 다음과 같다.
  - 초기 보스: 룬 장벽
  - 중간 보스: 룬 장벽 → 돌출 벽
  - 후반 보스: 룬 장벽 → 돌출 벽 → 중력 룬
  - 최종 보스: 룬 장벽 → 돌출 벽 → 중력 룬 → 코어 보호막
- 활성 패턴은 기존 패턴이 남아 있어도 다음 패턴을 발동할 수 있으며, 패턴별 오브젝트는 생존 시간이 끝날 때까지 유지한다.

1. 룬 장벽
   - 세로형 충돌 장벽
   - 일정 시간 유지되며 공 충돌 횟수에 따라 제거
2. 돌출 벽
   - 생성 전 전조 표시
   - 이후 돌출되어 공의 진행을 방해
3. 중력 룬
   - 일정 범위 안의 공 궤도를 강제로 변경
   - 중심에 접근하면 파괴
4. 코어 보호막
   - 보호막 룬 4개 생성
   - 유지 중 코어 피해 차단
   - 보호막 만료 시 룬 블록도 제거

## 공용 증원 패턴

- 모든 보스가 사용
- 현재 웨이브 번호만큼 블록 생성
  - W5: 5개
  - W10: 10개
  - W15: 15개
  - W20: 20개
- 일반·가드·폭발·회복·반사 블록을 순환 조합
- 보스 본체 아래쪽의 12열 × 6행 그리드에서 생성 셀을 결정론적으로 섞어 선택
- 일반 웨이브와 동일하게 블록 하나가 가로 2셀을 차지하며, 셀 안쪽 1px 여백을 둔 58×28px로 생성
- 보스 시작 시 1.2초 전조 후 최초 생성
- 증원 블록이 모두 제거되면 10초 후 재생성
- 재생성 직전에 1.2초 전조 표시
- 보스 전용 패턴과 독립적으로 동작

## 이미 반영된 디자인 규칙

- 코어는 2×2 단일 히트박스이며 본체 상단 중앙에 배치한다.
- 갑작스러운 증원 생성은 허용하지 않고 전조를 표시한다.
- 보스 전용 패턴과 공용 증원 패턴을 분리한다.
- 보스 기본 형태는 통일하고, 현재 발동 중인 패턴에 따라 외형과 장식이 변화한다.
- 패턴별 외형 변화는 색상과 발광 효과만 적용한다.
- 코어는 가장 밝고 강한 발광으로 강조하며, 장갑은 코어보다 어둡게 표현한다.
- 기본 장갑 8개를 모두 파괴하기 전에는 코어가 피해를 받지 않는다.
- 공용 증원 블록은 기본 장갑과 별개의 보스 패턴 오브젝트로 취급한다.
- 공용 증원 블록은 고정 행 배치가 아닌 보스 하단 제한 영역의 랜덤 배치로 생성한다.
- 기본 장갑이 모두 파괴된 뒤에도 특정 보스 패턴 발동 시 일부 장갑이 재생성될 수 있다.
- 장갑 재생성은 보스 HP가 특정 구간에 도달할 때 발동한다.
- 5·10웨이브 보스의 장갑 재생성은 HP 50% 이하에서 1회만 발동한다.
- 15·20웨이브 보스의 장갑 재생성 구간은 HP 75%·50%·25%이며, 각 구간은 보스당 1회만 발동한다.
- 각 HP 구간에 기본 장갑 4개를 재생성한다.
- 재생성 위치는 파괴된 기본 장갑 위치 중 무작위 4곳을 선택한다.
- HP 구간 장갑 재생성 전에도 1.2초 전조를 표시한다.
- 모든 기본 장갑이 파괴되면 코어 발광을 강화하고 `CORE EXPOSED` 표시를 보여준다.
- HP 구간에서 장갑이 하나라도 재생성되면 즉시 코어가 다시 보호된다.
- 재생성되는 장갑은 최초 장갑과 동일한 HP를 가진다.
- 재생성 수는 파괴된 장갑 수와 4 중 작은 값으로 정한다. 살아있는 장갑은 교체하지 않는다.
- 패턴 색상은 룬 장벽 보라색, 돌출 벽 파란색, 중력 룬 보라색 계열, 코어 보호막 금색으로 구분한다.
- 공용 증원 전조는 노란색 점선 생성 영역과 `REINFORCEMENTS INCOMING` 문구를 사용한다.
- 보스 전용 패턴은 기존 패턴이 남아 있어도 다음 패턴이 발동할 수 있다.
- 보스 전용 패턴은 보스 단계별 패턴 목록을 순서대로 순환한다.
- 룬 장벽과 돌출 벽은 재발동 시 기존 오브젝트를 제거하지 않고 새 오브젝트를 추가한다.
- 중력 룬은 기존 중력장과 독립적으로 누적되며, 플레이어의 블랙홀 스킬은 보스 패턴 색상 판정에 포함하지 않는다.
- 보스 웨이브 시작 연출은 `보스 등장 → 코어 경고 → 장갑 활성화` 순서로 진행한다.
- 보스 시작 연출의 전체 소요 시간은 약 3초로 한다.
- 단계별 시간은 보스 등장 1초, 코어 경고 1초, 장갑 활성화 1초로 동일하게 배분한다.
- 보스 등장 연출에서는 보스 이름 대신 `BOSS INCOMING` 문구를 표시한다.
- 코어 경고 단계에서는 `CORE WARNING` 문구를 표시한다.
- 장갑 활성화 단계에서는 `ARMOR ONLINE` 문구를 표시한다.
- `CORE EXPOSED` 상태는 장갑이 재생성될 때까지 유지한다.
- `CORE EXPOSED` 상태의 코어 피해량은 일반 블록과 동일하게 적용한다.
- 기본 장갑 보호와 코어 보호막은 별도로 중첩된다. 장갑을 모두 파괴해도 보호막 룬이 남아 있으면 코어는 보호된다.
- 장갑이 모두 파괴됐지만 보호막 룬이 남아 있으면 `CORE EXPOSED` 대신 `SHIELD ACTIVE`를 표시한다.
- `CORE EXPOSED` 상태에서 코어가 피격되면 강한 발광과 균열 효과를 표시한다.
- 기본 장갑이 파괴될 때마다 코어 발광이 잠시 증가한다.
- HP 구간 장갑 재생성 전조에는 `ARMOR REFORMING` 문구를 표시한다.
- 보스 시작 시 최초 장갑 활성화 문구는 `ARMOR ONLINE`으로 유지한다.
- 코어 보호막 룬은 각각 파괴될 때 작은 파괴 이펙트만 표시한다.
- 기본 장갑과 보호막이 모두 해제되어 코어 공격이 가능해지는 순간 `CORE EXPOSED`를 표시한다.
- 보스 코어 파괴 시 코어 폭발 후 보스 전체가 픽셀 단위로 붕괴한다.
- 보스 붕괴 후 클리어 문구는 `CORE DESTROYED`를 사용한다.
- `CORE DESTROYED`는 화면 전체를 덮는 클리어 오버레이로 표시한다.
- 클리어 오버레이는 약 2초 유지한 뒤 보스 보상 화면으로 전환한다.
- 보스 보상 화면은 검은 배경과 금색 장식 중심의 별도 화면으로 구성한다.
- 보스 보상 화면의 상단 제목은 `BOSS REWARD`로 표시한다.
- 보상 카드 내부 표기는 `LV3 + EVOLVE`를 유지한다.
- 보스 보상 화면 배경에는 금색 입자와 느린 빛의 파동을 사용한다.
- 보스 보상 카드는 3개를 표시한다.
- 보스 보상 후보는 현재 보유 중이며 아직 진화하지 않은 스킬만 사용한다.
- 후보가 3개보다 적으면 가능한 스킬 카드만 표시한다.
- 진화 가능한 보유 스킬이 없으면 일반 스킬 선택지를 대신 제공한다.
- 일반 스킬 대체 선택지도 3개를 표시한다.
- 일반 스킬 대체 선택지는 기존 웨이브 보상과 동일한 전체 일반 스킬 풀에서 뽑는다.
- 진화 가능한 보유 스킬이 없어 표시되는 일반 스킬 카드는 보스 보상 스타일을 유지하고 `ALTERNATE REWARD` 태그를 사용한다.
- 대체 카드에서 선택한 일반 스킬은 즉시 진화 상태로 지급한다.
- 미보유 스킬을 선택한 경우에도 해당 스킬을 LV3으로 획득한 뒤 즉시 진화시킨다.
- `ALTERNATE REWARD` 카드도 일반 보스 보상과 동일하게 진화 효과만 표시한다.
- `ALTERNATE REWARD` 카드의 단계 표기도 `LV3 + EVOLVE`로 통일한다.
- 보스 클리어와 보상 전환 사운드는 코어 파괴음, 짧은 정적, 보상 전용 사운드 순서로 재생한다.
- 픽셀 붕괴는 초반에는 느리게 진행하고 마지막에 빠르게 붕괴한다.
- 픽셀 붕괴 조각은 보스 본체의 현재 색상을 유지한다.
- 픽셀 붕괴 조각은 보스 중심에서 사방으로 퍼진다.
- 화면 흔들림은 코어 폭발 순간에 강하게 한 번만 발생한다.
- 보스 체력바에는 코어 HP만 표시한다. 장갑 수와 보호막 상태는 별도 UI에 표시하지 않는다.
- 공용 증원 블록 수와 재생성 대기시간은 보스 UI에 별도로 표시하지 않는다.
- 코어 HP는 화면 상단 중앙에 표시한다.
- 현재 발동 중인 보스 전용 패턴은 별도 UI 없이 색상과 이펙트로만 전달한다.
- 코어 HP 바는 일반적인 연속형 HP 바로 표시한다.
- 남은 기본 장갑 수는 별도 UI에 표시하지 않는다.
- 보호막 상태도 별도 UI에 표시하지 않고, 보호막 이펙트와 피해 무효화 피드백으로만 전달한다.
- 코어 HP 바는 기본 분홍색이며, HP가 낮아질수록 붉게 변화한다.
- 코어 HP 바는 위험 수준에서도 별도로 점멸하지 않고 색상 변화만 사용한다.
- `ARMOR REFORMING` 전조는 장갑과 같은 어두운 금속색으로 표시한다.
- `ARMOR REFORMING` 전조 중에는 재생성될 위치에 어두운 금속색 실루엣을 미리 표시한다.
- 재생성 위치 실루엣은 전조가 진행될수록 밝아지며 실제 장갑으로 전환된다.
- 장갑이 실제 블록으로 전환되는 순간 짧은 금속 충격파와 작은 파편 효과를 표시한다.
- 장갑 재생성 완료 시 짧은 금속 결합음을 재생한다.
- 보스 시작 시 `ARMOR ONLINE` 단계에서 모든 장갑이 동시에 활성화된다.
- 코어는 `CORE WARNING` 단계에서 먼저 활성화되고, 이후 장갑이 활성화된다.
- `CORE WARNING` 단계에서 코어는 천천히 밝아진다.
- `ARMOR ONLINE` 단계에서 모든 장갑에 짧은 금속 플래시를 동시에 표시한다.
- `BOSS INCOMING` 단계에서 보스 본체는 위에서 내려오며 등장한다.
- 보스 하강 중에는 잔상을 표시하고, 착지 순간에는 충격파를 표시한다.
- 보스 착지 순간에는 무거운 금속 착지음을 재생한다.
- 보스 시작 연출 중에는 플레이어의 패들 이동, 공 발사, 자동 발사, 스킬 발동, 공격 판정을 잠근다.
- 시작 연출 중에도 마우스 조준 방향은 갱신할 수 있으며, 연출 종료 후 클릭 발사 또는 기존 3초 대기 발사를 허용한다.
- 보스 페이즈 전환 전조 중에는 기존 전투를 유지하되, 해당 패턴의 공격 판정은 활성화 시점부터 적용한다.
- `BOSS INCOMING`, `CORE WARNING`, `ARMOR ONLINE` 문구는 보스 본체 바로 위에 표시한다.
- 보스 상태 문구는 픽셀 폰트와 현재 보스 패턴 색상을 사용한다.
- 보스 상태 문구는 단계 전환 시 짧게 점멸한 뒤 다음 문구로 변경한다.
- 시작 연출 문구 색상은 `BOSS INCOMING` 금색, `CORE WARNING` 청록색, `ARMOR ONLINE` 금속색으로 구분한다.
- 여러 보스 전용 패턴이 겹칠 때 보스 외곽 오라와 패턴 이펙트가 활성 패턴 색상들을 함께 표현한다.
- 중첩 패턴 색상은 활성 패턴 색상을 빠르게 순환해 표시한다.
- 중첩 패턴 색상은 1초마다 변경한다.
- 활성 패턴이 하나만 남으면 해당 패턴의 단일 색상으로 유지한다.
- 활성 보스 전용 패턴이 없을 때는 기본 보스 색상을 유지한다.
- 공용 증원 전조가 시작되는 순간부터 전조가 끝날 때까지 보스 외곽 오라 색상 순환에 노란색을 추가한다.
- 보스 전용 패턴이 활성화되어도 본체 발광 강도는 현재 수준을 유지한다.
- 코어는 패턴 색상 변화와 관계없이 항상 가장 밝은 상태를 유지한다.
- 장갑 자체는 패턴 색상으로 변경하지 않고 어두운 금속색을 유지한다.

## 앞으로 결정할 항목

- 보스 본체의 시각적 형태와 색상 단계
- 장갑 블록의 역할과 파괴 순서
- 패턴별 전조 연출과 위험도
