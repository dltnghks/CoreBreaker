# 스킬 피드백 및 변경안

스킬별 대화 피드백을 통해 확정된 기획·수치·구현 변경사항을 누적 기록한다.

## 전사 - 강타 (`warrior-smash`)

### 확정 변경안

- 역할: 직접 타격을 강화하는 단일 대상 핵심 스킬
- 피해 유형: 물리 피해
- 레벨 피해량: LV1 / LV2 / LV3 = `1 / 3 / 5`
- 공격 강화(`common-damage`) 적용
- 스킬 피해 강화(`common-skill-damage`) 미적용
- 가드 블록에는 발동하지 않음
- 범위 피해 없음
- 진화 효과: 피해량 증가 없이 쿨타임을 `0.4초`로 고정
- 실제 피해 계산: 스킬 기본 피해량 + 공통 물리 강화

### 구현 메모

- 현재 `warrior-smash`는 직접 타격 분기에서 처리되므로, 피해 타입과 고정 피해 적용 여부를 해당 경로에 반영해야 한다.
- 현재 설정에는 `smash`와 `splash` 특성이 함께 있으므로, 강타 진화의 범위 피해 로직은 제거하거나 비활성화해야 한다.

## 전사 - 충격파 (`warrior-shockwave`)

### 확정 변경안

- 역할: 주변 블록을 공격하는 범위 피해 핵심 스킬
- 피해 유형: 물리 피해
- 레벨 피해량: LV1 / LV2 / LV3 = `1 / 2 / 3`
- 공격 강화(`common-damage`) 적용
- 스킬 피해 강화(`common-skill-damage`) 미적용
- 원래 타격 대상 포함
- 범위 내 모든 블록 공격
- 기본 범위: `105 / 115 / 125px`
- 진화 효과: 범위 `+50px`
- 연쇄 효과 없음
- 기본 쿨타임: `4.0 / 3.5 / 3.0초`
- 실제 피해 계산: 스킬 기본 피해량 + 공통 물리 강화

### 구현 메모

- 현재 충격파 로직은 주변 대상 중심으로 처리되므로 원래 타격 대상도 피해 대상에 포함해야 한다.
- 대상 수 제한 없이 범위 내 모든 유효 블록을 처리해야 한다.
- 기존 `chain` 진화는 제거하고 범위 확장 진화로 변경해야 한다.

## 전사 - 처형 (`warrior-execute`)

### 확정 변경안

- 기존 즉시 파괴 효과 제거
- 역할: 대상 HP가 낮을수록 직접 타격 피해를 증폭하는 스킬
- HP 100%에서 기본 배율
- HP 25%에서 최대 배율
- HP 25% 이하에서는 최대 배율 유지
- 최대 배율: LV1 / LV2 / LV3 = `1.5 / 2 / 3배`
- 기본 공격과 다른 직접 타격 스킬 피해에 함께 적용
- 기본 쿨타임: `4.0 / 3.0 / 2.0초`
- 진화 효과: 최대 배율 도달 기준을 HP 25%에서 HP 40%로 완화
- 보스 코어 적용 시 일반 블록의 절반 배율만 적용

### 구현 메모

- 기존 `execute`는 HP 임계값에서 남은 HP를 전부 깎는 방식이므로, HP 비율 기반 선형 배율 계산으로 교체해야 한다.
- 처형 배율은 기본 공격 피해와 직접 타격 스킬 피해의 합산값에 적용한다.
- 보스 코어 대상일 때 계산된 추가 배율을 50%로 감쇠한다.

## 전사 - 분쇄 (`warrior-crush`)

### 확정 변경안

- 역할: 가드·힐러·반사 등 특수 블록 대응 전용 보조 스킬
- 일반 블록에는 추가 피해를 주지 않음
- 특수 블록 대상 추가 피해량: LV1 / LV2 / LV3 = `1 / 2 / 3`
- 공격 강화(`common-damage`) 적용
- 스킬 피해 강화(`common-skill-damage`) 미적용
- 실제 피해 계산: 스킬 기본 피해량 + 공통 물리 강화
- 진화 시 가드 상태를 무시하고 실제 피해 적용
- 진화 시 반사 블록의 반사 효과 무시

## 전사 - 철벽 (`warrior-guard`)

### 확정 변경안

- 역할: CORE 피해를 막는 방어 충전 스킬
- 발동 1회당 방어 충전 1회
- 기본 최대 저장 수: 1회
- 진화 후 최대 저장 수: 4회
- 기본 쿨타임: LV1 / LV2 / LV3 = `15 / 12 / 8초`
- 진화 효과: 최대 저장 수를 4회로 증가하는 것만 적용

## 궁수 - 연사 (`archer-rapid`)

### 확정 변경안

- 역할: 임시 화살을 여러 개 생성하는 핵심 공격 스킬
- 기본 발동 시 임시 화살 2발 생성
- 임시 화살 유지시간: LV1 / LV2 / LV3 = `5 / 7 / 9초`
- 진화 효과: 생성된 화살은 원본 공과 독립적으로 존재
- 진화 화살도 화면 아래로 떨어지거나 웨이브가 종료되면 사라짐

## 궁수 - 관통 화살 (`archer-pierce`)

### 확정 변경안

- 역할: 공이 여러 블록을 관통하는 핵심 공격 스킬
- 관통 횟수: LV1 / LV2 / LV3 = `1 / 2 / 3회`
- 관통하는 각 블록에 일반 공과 동일한 피해 적용
- 관통에 따른 피해 감소 없음
- 일반 공과 동일하게 기본 물리 피해 + 공통 물리 강화 적용
- 진화 효과: 가드·반사 블록도 관통 가능

## 궁수 - 튕김 화살 (`archer-ricochet`)

### 확정 변경안

- 역할: 주변 블록으로 공격을 전파하는 연쇄 공격 스킬
- 연쇄 대상 수: LV1 / LV2 / LV3 = `1 / 2 / 3개`
- 연쇄된 각 대상에 원래 타격과 동일한 피해 적용
- 일반 공과 동일하게 기본 물리 피해 + 공통 물리 강화 적용
- 진화 효과: 연쇄 범위 `+50px` 및 연쇄 대상 수 `+2개`
- 연쇄 순서가 뒤로 갈수록 피해 증가: 1회차 `1.0배`, 이후 매 회차 `+0.5배`
- 진화로 추가되는 4·5번째 연쇄에도 동일한 피해 증가 적용

## 궁수 - 집중 사격 (`archer-focus`)

### 확정 변경안

- 역할: 같은 블록을 반복 타격할수록 받는 피해가 증가하는 누적 약화 스킬
- 중첩당 받는 피해 증가량: LV1 / LV2 / LV3 = `10 / 20 / 30%`
- 최대 중첩: `3중첩`
- 최대 약화량: LV1 / LV2 / LV3 = `30 / 60 / 90%`
- 기본 중첩은 일정 시간 타격이 없으면 초기화
- 기본 중첩 초기화 시간: `3초`
- 진화 시 중첩이 웨이브가 끝날 때까지 유지

## 궁수 - 약점 공격 (`archer-weakpoint`)

### 확정 변경안

- 역할: 모든 직접 타격 피해를 증가시키는 단일 대상 화력 스킬
- 직접 타격 배율: LV1 / LV2 / LV3 = `2 / 2.5 / 3배`
- 진화 효과: 레벨과 관계없이 직접 타격 배율을 `4배`로 적용

## 마법사 - 화염 봉인 (`mage-fireball`)

### 확정 변경안

- 역할: 주변 모든 블록의 회복을 차단하는 광역 제어 스킬
- 직접 피해 없음
- 범위 내 모든 블록에 회복 차단 적용
- 범위: LV1 / LV2 / LV3 = `100 / 125 / 150px`
- 회복 차단 지속시간: LV1 / LV2 / LV3 = `2 / 4 / 6초`
- 진화 효과: 범위 내 블록에 화상 지속 피해 추가
- 진화 화상 피해: 초당 `1` 고정 마법 피해
- 화상 지속시간: 회복 차단과 동일한 `2 / 4 / 6초`

## 공통 - 아이템 자석 (`common-magnet`)

### 확정 변경안

- 역할: 아이템 획득 범위를 증가시키는 패시브
- 획득 범위: LV1 / LV2 / LV3 = `70 / 120 / 180px`
- 진화 효과: 화면 전체의 아이템을 끌어옴

## 공통 - 행운 (`common-luck`)

### 확정 변경안

- 역할: 아이템 드롭 확률을 증가시키는 패시브
- 드롭 확률 증가: LV1 / LV2 / LV3 = `8 / 14 / 20%`
- 진화 효과: 아이템 드롭 시 `50%` 확률로 추가 아이템 생성
- 추가 아이템 판정 시점: 아이템 드롭 순간
- 웨이브당 추가 아이템 생성 횟수 제한 없음

## 공통 - 패들 확장 (`common-wide`)

### 확정 변경안

- 역할: 패들 폭을 직접 증가시키는 패시브
- 패들 폭 증가량: LV1 / LV2 / LV3 = `+50 / +100 / +150px`
- 진화 효과: 패들 폭 추가 `+50px`

## 공통 - 패들 가속 (`common-move-speed`)

### 확정 변경안

- 역할: 패들의 좌우 이동속도를 증가시키는 패시브
- 이동속도 증가량: LV1 / LV2 / LV3 = `15 / 25 / 40%`
- 진화 효과: 이동속도 증가량 추가 `+20%`

## 공통 - CORE 강화 (`common-xp`)

### 확정 변경안

- 역할: CORE 최대 체력과 현재 체력을 함께 증가시키는 패시브
- 체력 증가량: LV1 / LV2 / LV3 = `+1 / +2 / +3HP`
- 진화 효과: 웨이브 시작 시 CORE 체력 `+1` 회복

## 공통 - 콤보 증폭 (`common-combo`)

### 확정 변경안

- 스킬 제거
- 콤보 점수 보너스 패시브를 선택 풀에서 제외
- 구현 시 설정, 선택 풀, 진화 데이터, 런타임 참조를 함께 정리

## 공통 - 공 크기 (`common-ball-size`)

### 확정 변경안

- 스킬 제거
- 선택 풀과 진화 데이터에서 제외
- 공 생성 시 반지름 보정 및 관련 런타임 참조 정리

## 공통 - 범위 증가 (`common-skill-range`)

### 확정 변경안

- 역할: 광역 스킬의 적용 범위를 증가시키는 패시브
- 적용 대상: 광역 스킬에만 적용
- 범위 증가량: LV1 / LV2 / LV3 = `20 / 40 / 60%`
- 진화 효과: 광역 범위 추가 `+50px`

## 공통 - 연계 강화 (`common-chain`)

### 확정 변경안

- 역할: 연쇄 스킬의 연결 대상 수를 증가시키는 패시브
- 기본 연결 대상 수 증가: `+1개`
- 진화 효과: 연결 대상 수 추가 `+3개`

## 공통 - 공격 강화 (`common-damage`)

### 확정 변경안

- 역할: 모든 물리 스킬 피해를 증가시키는 패시브
- 물리 스킬 피해 증가: LV1 / LV2 / LV3 = `+1 / +2 / +3`
- 진화 효과: 물리 스킬 피해 추가 `+3`
- 일반 공 피해와 모든 물리 스킬 피해에 적용

## 공통 - 마력 강화 (`common-magic`)

### 확정 변경안

- 역할: 모든 마법 스킬 피해를 증가시키는 패시브
- 마법 스킬 피해 증가: LV1 / LV2 / LV3 = `+1 / +2 / +3`
- 퍼센트 배율은 사용하지 않음
- 진화 효과: 마법 스킬 피해 추가 `+3`

## 공통 - 재사용 감소 (`common-cooldown`)

### 확정 변경안

- 역할: 모든 액티브 스킬의 쿨타임을 감소시키는 패시브
- 쿨타임 감소: LV1 / LV2 / LV3 = `10 / 20 / 30%`
- 진화 효과: 액티브 스킬 발동 시 `20%` 확률로 쿨타임 즉시 초기화

## 공통 - 스킬 피해 강화 (`common-skill-damage`)

### 확정 변경안

- 스킬 제거
- 물리 스킬 피해는 `공격 강화`가 담당
- 마법 스킬 피해는 `마력 강화`가 담당
- 선택 풀, 진화 데이터, 피해 계산 런타임 참조 정리

## 공통 - 스킬 지속 강화 (`common-skill-duration`)

### 확정 변경안

- 역할: 상태 이상·화상·회복 차단·동결·봉인·필드 등 모든 지속 효과의 시간을 증가시키는 패시브
- 지속시간 증가: LV1 / LV2 / LV3 = `10 / 20 / 30%`
- 블랙홀 등 필드 스킬에도 적용
- 진화 효과: 모든 지속 효과에 추가 `+30%`

## 마법사 - 연쇄 번개 (`mage-lightning`)

### 확정 변경안

- 역할: 여러 블록에 피해를 분산하는 광역 연쇄 공격
- 연결 대상 수: LV1 / LV2 / LV3 = `2 / 4 / 6개`
- 연결 대상 수와 대상당 피해량을 동일하게 적용
- LV1: `2개 대상 × 2피해` = 총 4 피해
- LV2: `4개 대상 × 4피해` = 총 16 피해
- LV3: `6개 대상 × 6피해` = 총 36 피해
- 대상당 피해는 고정 마법 피해로 처리
- 진화 시 연결 대상 수 `+3개`
- 진화 시 대상당 피해량: `연결 대상 수 × 0.5 + 공통 마법 강화`
- 진화 기준 대상 수: LV1 / LV2 / LV3 = `5 / 7 / 9개`
- 진화 기준 대상당 기본 피해: `2.5 / 3.5 / 4.5` + 공통 마법 강화
- 진화 기준 총 기본 피해: `12.5 / 24.5 / 40.5` + 대상 수에 따른 공통 마법 강화 합산

## 마법사 - 동결 의식 (`mage-freeze`)

### 확정 변경안

- 역할: 적을 얼리고 다음 직접 타격을 강화하는 제어 스킬
- 동결 지속시간: LV1 / LV2 / LV3 = `2 / 4 / 6초`
- 동결된 대상의 다음 직접 타격에 추가 피해 적용
- 추가 피해: LV1 / LV2 / LV3 = `1 / 2 / 3 × 마법 공격력`
- 진화 효과: 동결 종료 시 주변 블록으로 동결 확산

## 마법사 - 블랙홀 (`mage-black-hole`)

### 확정 변경안

- 역할: 공을 끌어모으는 필드 스킬
- 필드 생성 위치: 스킬이 충돌한 블록의 중심
- 생성 블록이 파괴되어도 필드는 남은 지속시간 동안 유지
- 기본: 블록 피해 없음, 공 제어 전용
- 진화: 필드 내 블록에 지속 피해 추가
- 필드 범위: LV1 / LV2 / LV3 = `100 / 150 / 200px`
- 기본 지속시간: `4초`
- 필드 안에 들어온 공을 강하게 중심으로 끌어당김
- 진화 시 필드 내 블록에 초당 `1` 고정 마법 피해

## 마법사 - 마나 봉인 (`mage-mana-blast`)

### 확정 변경안

- 역할: 가드·힐러·반사 등 특수 블록 기능을 봉인하는 카운터 스킬
- 특수 블록에만 적용
- 기능 봉인 지속시간: LV1 / LV2 / LV3 = `5 / 8 / 11초`
- 직접 피해 없음

## 이후 기록 규칙

- 스킬별로 `확정 변경안`, `미결정 사항`, `구현 메모`를 유지한다.
- 새로 결정된 내용은 기존 결정을 덮어쓰지 않고 해당 스킬 항목에 최신안으로 정리한다.
